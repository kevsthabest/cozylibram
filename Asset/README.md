# Cozy Libram Visual Assets

Web-native SVG asset pack for Cozy Libram's midnight library theme.

## Tags / intended use

| Asset | Tags | Intended use |
|---|---|---|
| `floral-right.svg` | `floral, botanical, right-edge, desktop, decoration, transparent` | Right-side Book Details/modal/page accent |
| `floral-corner.svg` | `floral, botanical, corner, card, decoration, transparent` | Book cards, empty states, modal corners |
| `divider-botanical.svg` | `divider, separator, botanical, section, transparent` | Section headings and content separators |
| `moon-sparkle.svg` | `celestial, moon, sparkle, decorative, transparent` | Discover headers, empty states, loading/brand accents |
| `book-frame.svg` | `frame, book, cover, card, decorative, transparent` | Book-cover presentation and featured-book cards |
| `book-icons.svg` | `icons, books, reading, ui, line-art, transparent` | Small UI actions and feature tiles |
| `mood-badges.svg` | `mood, rating, genre, badge, romance, spice, fantasy, dark` | Genre/mood/rating surfaces |
| `library-scene.svg` | `illustration, library, empty-state, loading, decorative` | Empty states, onboarding, larger decorative areas |

## Design tokens

- Background: midnight navy / indigo
- Primary metallic: warm antique gold
- Accent: dusty rose
- Secondary accent: muted violet
- Botanical secondary: muted sage
- Style: thin linework, subtle glow, literary/fantasy, candlelit
- Assets are transparent unless explicitly noted.

## Usage

Prefer SVGs as img or CSS backgrounds when decorative. Keep semantic information in HTML rather than inside illustrations.

For decorative images, use an empty alt attribute or aria-hidden=true.

These assets are intentionally lightweight and scalable.
